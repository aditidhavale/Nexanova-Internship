Task 1 : Trainer and Subject Management System
The Trainer and Subject Management System is a web-based application designed to maintain trainer information and subject details within an institute. The application enables administrators to add, view, and delete trainer records. It also allows the management of subjects and their association with trainers.
The system provides RESTful APIs and corresponding frontend pages developed using HTML, CSS, and JavaScript framework technologies. The application ensures easy retrieval of information related to trainers and subjects.

Task 2 : Training Institute Management System using Microservices Architecture
The Training Institute Management System is a web-based application developed using microservices architecture. The system consists of services such as Authentication Service, Course Management Service, Scheduling Service, Enrollment Service, and Timetable Service.
The API Gateway acts as a centralized entry point for all client requests and routes them to the appropriate services after validating authentication tokens. The system improves operational efficiency by reducing manual work involved in managing training schedules and enrollments.

Task 3 : Mock Evaluation Process Management System
The Mock Evaluation Process Management System is a web-based application developed to streamline the evaluation process conducted in training institutes. The system enables administrators to configure batches, technologies, evaluation rounds, assign evaluators, and monitor participant performance.
Evaluators can access their assigned participants, conduct evaluations, submit scores, and provide feedback. Reports can be generated to analyze participant performance across different technologies and rounds.

Task 4 : : Online Quiz Application for Internal Students
The Online Quiz Application is a web-based system developed for conducting internal assessments efficiently. The application provides two roles: Admin/Trainer and Student.
The Admin can manage subjects, topics, questions, quizzes, and student accounts. Students can log in, attempt scheduled quizzes, navigate questions, and view overall performance reports.
The system ensures secure authentication, time-bound quizzes, automatic submission, and detailed result analysis.
